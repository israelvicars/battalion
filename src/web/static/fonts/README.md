# Battalion fonts

These vendored fonts are served same-origin by the local UI.

- **Bungee** — source: https://github.com/google/fonts/tree/main/ofl/bungee; license: SIL Open Font License 1.1 (`Bungee-OFL.txt`).
- **Inter v4.1** — source: https://github.com/rsms/inter/releases/tag/v4.1; license: SIL Open Font License 1.1 (`Inter-OFL.txt`).
- **JetBrains Mono v2.304** — source: https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304; license: SIL Open Font License 1.1 (`JetBrainsMono-OFL.txt`).

The files were subset to Latin (U+0000-00FF plus common punctuation/arrows) and converted to WOFF2 with `fontTools pyftsubset`.
